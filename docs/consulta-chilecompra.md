# Consulta a ChileCompra – acceso a documentos de procesos vía API

Canal: formulario de sugerencias de https://www.chilecompra.cl/api/ (respuesta en hasta 3 días hábiles).

---

**Asunto:** Consulta sobre acceso a documentos adjuntos de licitaciones y Compras Ágiles mediante API

Estimados:

Somos usuarios de la API de Mercado Público (ticket a nombre de Patricio Cisterna) y estamos desarrollando una herramienta para que proveedores identifiquen oportunidades y revisen los requisitos de cada proceso.

Las APIs de Licitaciones y de Compra Ágil v2 nos entregan los datos de cada proceso, pero no permiten descargar sus documentos adjuntos (bases administrativas y técnicas, anexos y formularios). En Compra Ágil v2 solo recibimos el identificador y el nombre de cada documento.

Queremos hacer las cosas por la vía correcta, por lo que consultamos:

1. ¿Existe un endpoint oficial, actual o planificado, para descargar los documentos adjuntos de una licitación o Compra Ágil a partir de su código o del identificador del documento?
2. ¿Los datos abiertos en estándar OCDS incluyen enlaces descargables a esos documentos? Si es así, ¿cuál es la URL de la API y su documentación?
3. Si no existe una vía automatizada, ¿cuál es el uso aceptable para descargar documentos de procesos puntuales, a solicitud de un usuario y a baja frecuencia?

Agradecemos su orientación.
